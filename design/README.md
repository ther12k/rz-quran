# Design Reference Pack

Open `gallery.html` in a browser. It loads only local files and contains no analytics, external fonts or JavaScript dependencies. The six original PNGs are preserved byte-for-byte in `mockups/`; their hashes and origin filenames are in `asset-manifest.json`. `contact-sheet.jpg` is a labeled overview assembled from those same files, not a new set of designs.

The concepts cover home, catalog, short-surah practice, quiz, game and parent progress. They are AI-generated flat images, not Figma source files, a working app or verified Qur'an assets. Generated Arabic/calligraphy and all depicted learning statistics are unverified/fictional. Do not extract them as canonical content.

Follow `../docs/02_UX_SPEC.md` for the definitive responsive behavior and concept corrections. `screen-inventory.json` includes 21 specified screen types and honestly marks missing visual designs. `tokens.json`, `tokens.css` and `indonesian-copy.json` are implementation inputs, not production-tested components.

Recreate or license production illustrations/fonts and document their rights. No font files are distributed. Parent gates, onboarding, ayah-player detail, privacy, error states and admin screens still need implementation screenshots and review.
